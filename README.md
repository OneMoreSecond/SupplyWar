# Supply War MVP

Browser prototype for a supply-route strategy game. Capture the enemy resource to break its support transport, siege the frontline, then bypass the enemy backup to take the base.

Requires Node 22+ and npm.

```bash
npm install
npm run dev
```

Validation:

```bash
npm run typecheck
npm test
npm run build
```

The detailed design, balance model, and acceptance criteria are in [the MVP plan](agents/progress/2026-08-26-game-demo-plan-grill.md).
